## 挂件结构概述

每个挂件由两个核心文件组成：

```
src/view/decorate/wgts/wgt_[name]/
├── config.js      # 配置文件：定义挂件的设置项、数据转换逻辑
└── index.vue      # 渲染组件：定义挂件的展示逻辑和样式
```

### 挂件命名规范

- 文件夹名：`wgt_[name]`（小写，单词用短横线分隔）
- 配置中的 name：`[name]`（驼峰命名，如 `film`, `couponCard`, `storeAlphabet`）

## 核心组件说明

### 1. 配置组件 (configsetting.js)

**位置**: `src/view/decorate/comps/configsetting.js`

**作用**: 自动处理挂件配置，为所有挂件添加通用配置项，并自动识别和转换 CompStyle 配置。

**自动添加的配置项**:
- `outerMargin`（组件外边距）- 所有挂件自动添加
- `innerPadding`（组件内边距）- 特定挂件自动添加（如 `speedkill`, `group`, `shop`, `couponCard`, `storeAlphabet` 等）
- `tags`（人群设置）- 所有挂件自动添加
- `track`（埋点参数）- 所有挂件自动添加

**使用方法**:
```javascript
import '../../comps/configsetting'

export default (typeof globalThis !== 'undefined' && globalThis.__processConfig__)
  ? globalThis.__processConfig__(config)
  : config
```

### 2. 样式组件

#### CompStyle (comp_style.vue)
用于配置边距（padding/margin）的组件。

**使用场景**:
- `outerMargin`: 组件外边距
- `innerPadding`: 组件内边距

**示例**:
```javascript
{
  label: '组件内边距',
  key: 'innerPadding',
  component: function (h, { key }) {
    return (
      <CompStyle
        v-model={this.value[key]}
        uuid={this.value.uuid}
        showTop={true}
        showBottom={true}
        showLeft={true}
        showRight={true}
      />
    )
  },
  value: {
    paddedt: 16,
    paddedb: 16,
    paddedl: 16,
    paddedr: 16
  }
}
```

#### CompOuter (comp_outer.vue)
用于配置组件外背景（颜色、图片）。

**示例**:
```javascript
{
  label: '组件外背景',
  key: 'outerBackground',
  component: function (h, { key }) {
    return <CompOuter v-model={this.value[key]} uuid={this.value.uuid} />
  },
  value: { color: '#f8f8f8', image: '' }
}
```

#### CompInner (comp_inner.vue)
用于配置组件内背景（纯色、渐变）。

**示例**:
```javascript
{
  label: '组件内背景',
  key: 'innerBackground',
  component: function (h, { key }) {
    return <CompInner v-model={this.value[key]} uuid={this.value.uuid} />
  },
  value: { type: 'solid', color: '#ffffff', startColor: '#ffffff', endColor: '#ffffff' }
}
```

#### CompButton (comp-button.vue)
用于触发选择器（如优惠券选择器、商品选择器等）。

**示例** (wgt_coupon/config.js):
```javascript
{
  label: '数据设置',
  key: 'data',
  component: function (h, { key }) {
    return (
      <CompButton
        placeholder="选择优惠券"
        format="{0}个优惠券"

          const { data: couponData } = await self.$picker.coupon({
```

### 4. 链接选择与媒体选择器组件

#### CompPickerLink（链接/路径选择）

**位置**: `src/view/decorate/comps/comp-pickerLink.vue`

**作用**: 配置「跳转链接」：支持「选择路径」（商品、分类、自定义页面等）或「H5 链接」，并带埋点参数。

**绑定值 (v-model) 结构**:
```javascript
{
  linkType: 0,        // 0=选择路径, 1=H5链接
  linkUrl: '',        // H5 链接地址（linkType=1 时使用）
  linkPage: '',       // 路径类型（如 goods, category, custom_page）
  id: '',             // 路径对应 id
  title: '',          // 路径显示标题
  trackingParams: ''  // 埋点参数
}
```

**Props**:
- `value`：同上，支持 `v-model`
- `isShowH5Link`：是否显示「H5链接」选项，默认 `true`
- `tabs`（可选）：路径选择器中的 Tab 配置。可从 `@/consts` 引入：
  - `DEFAULT_PICKER_TABS`：默认页面/路径 Tab
  - `PLATFORM_PAGE_PICKER_TABS`：平台场景（如 `scene=1010`）下的 Tab

**在 config.js 中的用法**:

基础用法（不指定 tabs，使用选择器默认 Tab）:
```javascript
import CompPickerLink from '../../comps/comp-pickerLink'

// 在 setting 中
{
  label: '更多链接',
  key: 'moreLink',
  component: function (h, { key }) {
    return <CompPickerLink v-model={this.value[key]} style='margin-top: 7px;' />
  },
  value: {}
}
```

指定路径 Tab（如商品、排行榜等挂件的「更多」按钮链接）:
```javascript
import CompPickerLinkVue from '../../comps/comp-pickerLink.vue'
import { PLATFORM_PAGE_PICKER_TABS, DEFAULT_PICKER_TABS } from '@/consts'

// 在 setting 中
{
  label: '更多链接',
  key: 'speedkillMoreLink',
  component: function (h, { key }) {
    return (
      <CompPickerLinkVue
        v-model={this.value[key]}
        style='margin-top: 7px;'
        tabs={this.$route.query.scene == '1010' ? PLATFORM_PAGE_PICKER_TABS : DEFAULT_PICKER_TABS}
      />
    )
  },
  value: {}
}
```

**参考挂件**: `wgt_speedkill`、`wgt_ranking`、`wgt_hotranking`、`wgt_group`、`wgt_goods`、`wgt_goodsScroll`、`wgt_goodsGrid`、`wgt_goodsGridTab`。

#### 通过 $picker 调用的选择器（在 CompButton / 自定义 component 内）

在挂件 config 或 attr 中，常用 `this.$picker.xxx()` 打开各类选择弹窗，与「链接」相关的常用方法包括：

| 方法 | 说明 | 典型参数 |
|------|------|----------|
| `this.$picker.path(options)` | 路径/链接选择（商品、分类、页面等） | `{ data, tab, multiple, guide }` |
| `this.$picker.coupon(options)` | 优惠券选择 | `{ data, multiple, params }` |
| `this.$picker.image(options)` | 图片选择 | - |
| `this.$picker.store(options)` / `this.$picker.shop(options)` | 店铺选择 | - |
| `this.$picker.goods(options)` | 商品选择 | - |
| `this.$picker.goodsitem(options)` | 商品项选择 | - |
| `this.$picker.category(options)` | 分类选择 | - |
| `this.$picker.tag(options)` | 标签选择 | - |

链接类配置若只需「路径 + 埋点」，可直接使用 **CompPickerLink**；若需在自定义 UI 里弹选择器，再在 `on-click` 中调用 `this.$picker.path(...)` 并 `$set` 到对应 key。

## 配置文件 (config.js)

### 基本结构

```javascript
import { pickBy } from '@/utils'
import { transformInBase, createTransformOutBase } from '../../comps/transform-utils'

const config = {
  name: 'widgetName',  // 挂件名称（驼峰命名）
  setting: [
    // 配置项数组
  ],
  transformIn: (v) => {
    // 数据输入转换：从后端数据转换为前端使用的格式
  },
  transformOut: (v) => {
    // 数据输出转换：从前端数据转换为后端需要的格式
  }
}

// 自动处理配置
import '../../comps/configsetting'
export default (typeof globalThis !== 'undefined' && globalThis.__processConfig__)
  ? globalThis.__processConfig__(config)
  : config
```

### setting 配置项格式

```javascript
{
  label: '配置项标签',        // 显示在配置面板中的标签
  key: 'configKey',          // 配置项的 key，对应 value 对象中的属性
  component: 'input',        // 组件类型：'input', 'select', 'switch', 'color', 'radiobutton' 等
  value: defaultValue,       // 默认值
  group: '分组名称',         // 可选：配置项分组
  options: [],              // 可选：select/radiobutton 的选项数组
  isShow: function() {      // 可选：条件显示函数
    return this.value.someCondition
  },
  onchange: function(e, vm) { // 可选：值变化时的回调
    // 处理逻辑
  }
}
```

### 常用组件类型

- `'input'`: 文本输入框
- `'select'`: 下拉选择框（需要提供 `options`）
- `'switch'`: 开关
- `'color'`: 颜色选择器
- `'radiobutton'`: 单选按钮组（需要提供 `options`）
- `function (h, { key })`: 自定义组件（JSX 语法）

## 公共方法

### transform-utils.js

**位置**: `src/view/decorate/comps/transform-utils.js`

#### transformInBase(base, styleKeys)

将后端数据中的样式字段（`outerMargin`, `innerPadding`）从 rpx 转换为 px。

**参数**:
- `base`: 后端返回的 base 对象
- `styleKeys`: 需要转换的样式键数组，如 `['outerMargin', 'innerPadding']`

**返回值**: 转换后的 base 对象

**示例**:
```javascript
transformIn: (v) => {
  const { name, base, data } = v
  const transformedBase = transformInBase(base, ['outerMargin', 'innerPadding'])
  return {
    name,
    ...transformedBase,  // 展开转换后的样式数据
    data
  }
}
```

#### createTransformOutBase(baseKeys, styleKeys)

创建标准的 `transformOut` 中的 base 处理函数，将样式字段从 px 转换为 rpx，并提取指定字段。

**参数**:
- `baseKeys`: base 中需要提取的键数组，如 `['outerMargin', 'innerPadding', 'outerBackground', 'innerBackground']`
- `styleKeys`: 需要转换的样式键数组，如 `['outerMargin', 'innerPadding']`

**返回值**: base 处理函数

**示例**:
```javascript
transformOut: (v) => {
  return pickBy(v, {
    name: 'name',
    base: (v) => {
      const baseData = createTransformOutBase(
        ['outerMargin', 'innerPadding', 'outerBackground', 'innerBackground'],
        ['outerMargin', 'innerPadding']
      )(v)
      return baseData
    },
    data: 'data'
  })
}
```

#### convertRpxToPx(marginObj)

将 rpx 单位转换为 px（除以 2）。

**参数**: `marginObj` - 包含 `paddedt`, `paddedb`, `paddedl`, `paddedr` 的对象

**返回值**: 转换后的对象

#### convertPxToRpx(marginObj)

将 px 单位转换为 rpx（乘以 2）。

**参数**: `marginObj` - 包含 `paddedt`, `paddedb`, `paddedl`, `paddedr` 的对象

**返回值**: 转换后的对象

### style-utils.js

**位置**: `src/view/decorate/comps/style-utils.js`

#### getOuterStyle(value)

计算外层样式（`outerStyle`），包含外边距和外背景。

**参数**: `value` - 挂件的 value 对象

**返回值**: 样式对象，包含：
- `paddingTop`, `paddingBottom`, `paddingLeft`, `paddingRight`
- `backgroundColor`, `backgroundImage`, `backgroundSize`, `backgroundPosition`, `backgroundRepeat`

**支持的数据格式**:
1. 新格式：`outerMargin` + `outerBackground`
2. 旧格式：背景数据存储在 `outerMargin` 中（`bgType`, `bgColor`, `bgPic` 等）

**示例**:
```javascript
computed: {
  outerStyle() {
    return getOuterStyle(this.value)
  }
}
```

#### getInnerStyle(value)

计算内层样式（`innerStyle`），包含内边距和内背景。

**参数**: `value` - 挂件的 value 对象

**返回值**: 样式对象，包含：
- `paddingTop`, `paddingBottom`, `paddingLeft`, `paddingRight`
- `backgroundColor`, `backgroundImage`

**支持的数据格式**:
1. 新格式：`innerPadding` + `innerBackground`
2. 旧格式：背景数据存储在 `innerPadding` 中（`bgType`, `bgColor`, `bgPic` 等）

**示例**:
```javascript
computed: {
  innerStyle() {
    return getInnerStyle(this.value)
  }
}
```

## 样式处理

### 样式数据格式

#### 外边距 (outerMargin)

```javascript
{
  paddedt: 16,  // 上边距（px）
  paddedb: 16,  // 下边距（px）
  paddedl: 16,  // 左边距（px）
  paddedr: 16   // 右边距（px）
}
```

#### 内边距 (innerPadding)

格式同 `outerMargin`。

#### 外背景 (outerBackground)

```javascript
{
  color: '#f8f8f8',  // 背景颜色
  image: ''          // 背景图片 URL
}
```

#### 内背景 (innerBackground)

```javascript
{
  type: 'solid',           // 'solid' | 'gradient'
  color: '#ffffff',        // 纯色背景颜色
  startColor: '#ffffff',   // 渐变起始颜色
  endColor: '#ffffff'      // 渐变结束颜色
}
```

### 样式单位转换

- **后端存储**: rpx（rpx = px * 2）
- **前端使用**: px
- **转换时机**:
  - `transformIn`: rpx → px（使用 `transformInBase`）
  - `transformOut`: px → rpx（使用 `createTransformOutBase`）

## 数据转换

### transformIn (数据输入)

将后端返回的数据转换为前端组件使用的格式。

**典型处理**:
1. 提取需要的字段（`name`, `base`, `data` 等）
2. 转换样式数据（rpx → px）
3. 处理嵌套数据结构
4. 设置默认值

**示例** (wgt_film/config.js):
```javascript
transformIn: (v) => {
  const { name, base, data, track, tagsType, meber_tags, no_meber_tags } = v
  // 使用公共函数处理 base 中的样式数据转换
  const transformedBase = transformInBase(base, ['outerMargin'])
  let _data = data.flat()[0] || {}
  return {
    id: v?.id,
    name,
    ...transformedBase,  // 展开转换后的样式数据
    data: _data,
    track,
    tags: {
      type: tagsType || '2',
      meber_tags: meber_tags || [],
      no_meber_tags: no_meber_tags || []
    }
  }
}
```

### transformOut (数据输出)

将前端组件的数据转换为后端需要的格式。

**典型处理**:
1. 使用 `pickBy` 提取需要的字段
2. 转换样式数据（px → rpx）
3. 处理嵌套数据结构
4. 格式化数据（如数组扁平化）

**示例** (wgt_coupon/config.js):
```javascript
transformOut: (v) => {
  return pickBy(v, {
    name: 'name',
    base: (v) => {
      // 使用公共函数处理 outerMargin 转换，同时保留其他字段
      const baseData = createTransformOutBase(
        ['wgtCustName', 'track', 'outerMargin', 'innerPadding', 'outerBackground', 'innerBackground', 'amountColor', 'receiveBtn'],
        ['outerMargin', 'innerPadding']
      )(v)
      return baseData
    },
    data: 'data',
    meber_tags: 'tags.meber_tags',
    no_meber_tags: 'tags.no_meber_tags',
    tagsType: 'tags.type'
  })
}
```

### pickBy 工具函数

**位置**: `@/utils`

**作用**: 从对象中提取指定字段，支持嵌套路径。

**用法**:
```javascript
pickBy(source, {
  field1: 'field1',                    // 直接提取
  field2: 'nested.field2',            // 嵌套路径
  field3: ({ nested }) => nested.data  // 函数提取
})
```

### 示例 2: wgt_coupon (优惠券挂件)

#### config.js

```javascript
import { pickBy } from '@/utils'
import moment from 'moment'
import CompButton from '../../comps/comp-button.vue'
import { transformInBase, createTransformOutBase } from '../../comps/transform-utils'

const config = {
  name: 'couponCard',
  setting: [
    {
      label: '数据设置',
      key: 'data',
      component: function (h, { key }) {
        const self = this
        return (
          <CompButton
            placeholder="选择优惠券"
            format="{0}个优惠券"
            value={self.value[key]?.length || 0}
            viewBtn={false}
            on-click={async () => {
              try {
                const couponList = self.value[key] || []
                const { data: couponData } = await self.$picker.coupon({
                  data: couponList,
                  multiple: true,
                  params: {
                    regionauth_id: self.$route.query.regionauth_id
                  }
                })
                
                const formattedCouponList = couponData.map((item) => {
                  let amount
                  if (item.card_type == 'cash') {
                    amount = item.reduce_cost / 100
                  } else if (item.card_type == 'discount') {
                    amount = (100 - parseInt(item.discount)) / 10
                  } else {
                    amount = item.reduce_cost / 100
                  }
                  return {
                    amount,
                    desc: item.description,
                    id: item.card_id,
                    title: item.title,
                    type: item.card_type,
                    end_date: moment(item.end_date * 1000).format('YYYY-MM-DD HH:mm'),
                    card_source: item?.card_source || '',
                    card_source_platform: '',
                    ...item
                  }
                })
                self.$set(self.value, key, formattedCouponList)
              } catch (error) {
                console.error('选择优惠券失败:', error)
              }
            }}
            on-remove={() => {
              self.$set(self.value, key, [])
            }}
          />
        )
      },
      value: []
    },
    {
      label: '面额颜色',
      key: 'amountColor',
      component: 'color',
      value: '#D4003B'
    },
    {
      label: '领取按钮',
      key: 'receiveBtn',
      component: function (h, { key }) {
        return <CompBtn v-model={this.value[key]} showImage={false} />
      },
      value: {
        color: '#000000',
        textColor: '#fff',
        image: ''
      }
    }
  ],

    const { name, base, data, meber_tags = [], no_meber_tags = [], tagsType } = v
    const transformedBase = transformInBase(base, ['outerMargin', 'innerPadding'])
    return {

      ...transformedBase,
      data,
      tags: {
        type: tagsType || '2',
        meber_tags: meber_tags || [],
        no_meber_tags: no_meber_tags || []
      }
    }
  },
  transformOut: (v) => {
    return pickBy(v, {
      name: 'name',
      base: (v) => {
        const baseData = createTransformOutBase(
          ['wgtCustName', 'track', 'outerMargin', 'innerPadding', 'outerBackground', 'innerBackground', 'amountColor', 'receiveBtn'],
          ['outerMargin', 'innerPadding']
        )(v)
        return baseData
      },
      data: 'data',
      meber_tags: 'tags.meber_tags',
      no_meber_tags: 'tags.no_meber_tags',
```

## 常见问题

### Q: 如何添加自定义样式配置项？

A: 在 `config.js` 的 `setting` 中添加配置项，使用 `CompStyle`、`CompOuter`、`CompInner` 等组件。

### Q: 如何添加数据选择器？

A: 使用 `CompButton` 组件触发选择器，或使用 `AttrStore`、`SpVideoPicker` 等专用选择器组件。

### Q: 样式单位如何转换？

A: 使用 `transformInBase`（rpx → px）和 `createTransformOutBase`（px → rpx）自动处理。

### Q: 如何条件显示配置项？

A: 在配置项中添加 `isShow` 函数：
```javascript
{
  key: 'data',
  isShow: function() {
    return this.value.dataType === 'specify'
  }
}
```

### Q: 如何监听配置项变化？

A: 在配置项中添加 `onchange` 回调：
```javascript
{
  key: 'dataType',
  onchange: function (e, vm) {
    vm.value.data = []
  }
}
```
