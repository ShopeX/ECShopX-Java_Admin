# 图片热区编辑设计

## 目标
为“图片热区”section 增加新弹窗式热区编辑能力，支持 PC / 移动两套独立热区配置，并沿用现有链接选择能力。

## 范围
- 仅覆盖图片热区 section
- 支持 PC 图片和移动图片分别配置热区
- 热区通过拖拽框选创建与调整
- 热区链接复用现有“设置路径”弹窗返回的完整 link 对象
- 同时支持 H5 自定义链接

## 数据结构
每个设备一套热区数组：
- `pc_hotspots: Hotspot[]`
- `mobile_hotspots: Hotspot[]`

单个热区对象建议包含：
- `id`: 热区唯一标识
- `rect`: `{ x, y, width, height }`
- `link`: 现有链接选择弹窗返回对象

## 交互流程
1. 用户在右侧配置区点击“添加热区”
2. 打开新弹窗
3. 弹窗顶部切换 `PC / 移动`
4. 中间显示对应设备图片
5. 用户拖拽框选热区
6. 选中热区后配置链接
7. 保存后写回当前设备对应热区数组

## 设备差异
- PC 和移动热区完全独立保存
- 切换设备时只编辑当前设备热区
- 预览渲染时按当前设备展示对应热区

## 链接方案
- 热区链接对象直接复用现有链接配置弹窗返回值
- 支持两种模式：
  - 路径选择
  - H5 链接

## UI 预期
- 右侧属性面板仅保留图片与热区入口
- 热区编辑在新弹窗完成，避免在属性面板中堆叠过多配置项
- 预览区热区可见，便于确认位置与链接

## 风险与约束
- 拖拽框选与图片缩放比例要保持一致
- 图片未上传时不可进入热区编辑
- 切换设备时需防止误编辑到另一端热区
